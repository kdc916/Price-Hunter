# Price Hunter v0.3.2 — 삼성 폴드 스크린샷 인식 개선

## v0.3.0 핵심 변경
- 쇼핑몰 스크린샷 한 장으로 **상품명 / 일반 판매가 / 할인 전 가격** 추출 정확도를 개선했습니다.
- 무료 Tesseract.js OCR이 실패하면 **원본 → 고대비 → 상단 집중 영역**, 최대 3회 다시 인식합니다.
- 분리된 OCR 결과에서 **가격과 상품명을 각각 추출·병합**하고 오인식된 포인트·적립금·할부비를 판매가에서 제외합니다.
- 삼성 갤럭시 Z 폴드8 5G 256GB 자급제 사례: 표시 판매가 1,993,540원 / 할인 전 2,208,300원 / 적립 20,170P 제외.
- 폴드 같은 마케팅명은 제조사 SKU로 취급하지 않으며, 정확한 SKU가 없으면 직접 확인하도록 안내합니다.
- 기존 기록과 수익 분석 로직은 그대로 유지하며 PWA 캐시는 v030으로 갱신합니다.

**검증:** 기존 회귀 테스트 및 OCR 오류 패턴 테스트. 실제 촬영 이미지의 Tesseract 결과는 기기별로 차이가 있으며 100% 보장하지 않습니다. 유료 API 사용 없음.

# Price Hunter v0.2.0 — 스크린샷 한 장으로 상품·가격 인식

**무료 HTML/PWA 상품 인식·시세 검증·수익 계산 도구**. 매장 가격표 또는 쇼핑몰 화면을 PNG/JPG/WebP 스크린샷 한 장으로 불러오면 자동으로 모델 코드/상품명/표시 판매가를 추출하고, 현재 저장된 동일 모델 중고 시세로 예상 순익을 표시합니다.

## 빠른 사용법
1. GitHub Pages 공개 후 HTTPS에서 접속하거나 `index.html`을 실행합니다. PWA와 바코드 기능은 지원 브라우저 및 HTTPS 필요.
2. 첫 탭에서 **사진 한 장**을 촬영/선택하거나 드래그 또는 클립보드 이미지 붙여넣기(Ctrl+V)를 합니다.
3. 첫 실행 시 Tesseract.js **한국어/영어 OCR** 모델을 무료 다운로드합니다(네트워크 및 브라우저 환경에 따라 시간 소요). 이미지는 브라우저 내에서 처리합니다.
4. 인식 결과에서 제품명/모델코드/표시 판매가가 맞는지 확인합니다. 정상가와 **로그인·쿠폰 조건부 가격**을 구분합니다.
5. 하단에서 최근 1/3/6개월·전체, 빠른 판매/중앙값/높은 판매가/평균, 수수료/배송비/이상치 제외를 선택합니다.
6. 검증한 동일 모델 중고 데이터가 3건 이상 있으면 **가정 기반 예상 순익과 ROI**가 계산됩니다. 미만이면 **판단 보류**, 거짓 임의 가격을 표시하지 않습니다.
7. **중고나라·당근·번개장터·네이버쇼핑** 등 무료 검색 링크로 이동해 실제 매물을 확인하고 `시세 검증` 탭에 기록합니다.

## LG 쇼핑몰 캡처 예시
- 상품 모델 `43NU810BENA`
- 표시 판매가 `593,330원`
- 할인 전 가격 `631,200원`
- 로그인 조건부 가격 `593,328원` (기본 구매가에 적용하지 않음)

작은 글씨 OCR에서 단위 문자 `원`이 다른 문자로 잘못 추출되는 경우 **낮은 신뢰도**로 표시하며 원문을 재확인할 수 있게 합니다. 모델/가격 자동 추출은 **100% 정확도를 보장하지 않습니다**.

## 실행 환경
- HTML, CSS, JavaScript만 사용 / **유료 API 없음**.
- `core.js`: 상품 매칭·중고통계·안전한 수익 계산.
- `screenshot.js`: **스크린샷 단일 입력 파서** — 제품/가격/조건부혜택/정상가 분리.
- `app.js`: OCR, 카메라 업로드, 클립보드·드롭, 검색 링크, 시세 기록, 즉시 결과.
- `sw.js`: 로컬 앱 캐시(PWA), 버전마다 갱신.
- `tests/*.test.js`: `node tests/core.test.js && node tests/screenshot.test.js`.

## 중요 제한
- **구글 검색의 일부 인덱싱된 중고 게시물**에 연결하는 것이지, 모든 매물의 가격을 자동으로 검색·확인하는 API는 제공하지 않습니다.
- 페이지에 표시된 판매완료 여부와 진짜 실거래 가격은 다릅니다. 미확인 가격을 거래가로 사용하지 않습니다.
- 구글 검색 링크를 새 탭으로 여는 방식이므로 검색 결과가 보이지 않거나 누락될 수 있습니다.
- 주제 이미지에 **텍스트/모델 코드가 없는 경우** OCR만으로 제품을 식별할 수 없으며, Google Lens 등을 사용해 제품을 재확인해야 합니다.
- API 비용은 없지만 외부 OCR 라이브러리/언어 데이터 다운로드는 네트워크가 필요합니다. 모든 상황에서 오프라인 완전 인식은 불가능합니다.
- 3.5% 수수료 등 계산기의 기본값은 **예시 가정**이며 플랫폼 공식 실제 수수료가 아닙니다.
- 웹앱은 재판매 가능성이나 수익 실현을 보장하지 않습니다. 반품·사업자/세금·직거래 리스크 별도.

## v0.3.2 — 가격표 적립금·포인트 오인식 방지 (2026-10-18)
- 새 `priceguard.js` 가격 판별기: **실제 판매가**, **정상가**, **회원·쿠폰 조건부 가격**, **적립·포인트·할인액·배송비**를 구분합니다.
- 3,109,090원 판매가 / 3,533,050원 정상가 / 68,181원 적립금이 함께 있는 소니 A7 V 화면에서 적립금을 구매가로 선택하지 않습니다.
- OCR에 표시된 금액이라도 `원` · `만원` · `천원` · `₩` 같은 통화 단위가 없으면 구매가로 자동 인식하지 않습니다. 단순 콤마 숫자 추론을 사용하지 않습니다.
- `할인 50,000원`은 할인액이므로 제외하지만 `할인가 3,109,090원`이나 `11% 3,109,090원`은 실제 판매가 후보입니다.
- 비슷한 가격 후보들이 충돌하거나 인식 신뢰도가 부족하면 **구매가 자동 입력을 보류**하여 잘못된 ROI 계산을 방지합니다. 후보 가격은 수동 검토할 수 있습니다.
- 사용자의 기존 제품·시세 기록은 보존하며, GitHub Pages PWA 캐시를 `price-hunter-v032`로 변경했습니다.
- 회귀 테스트: `node tests/priceguard_v032.test.js`, `node tests/core.test.js`, `node tests/screenshot.test.js`, `node tests/screenshot_v030.test.js`, `node tests/mobile_input_v031.test.js`.
- 제한: OCR 엔진이 원문을 심하게 잘못 읽으면 모델·가격 인식은 여전히 틀리거나 비워질 수 있습니다. 실기기 촬영 테스트와 중고 실거래 자동 검증은 별개 과제입니다.
