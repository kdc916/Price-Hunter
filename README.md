# Price Hunter v0.1.0

무료 API 및 회원가입 없이 사용하는 모바일 우선 PWA(Progressive Web App) 상품 가격·중고 시세 검증 도구입니다.

> **중요:** 현재 버전은 첫 실사용 프로토타입입니다. 브라우저에서 실제 가격을 자동 수집하거나 사진만으로 모든 제품을 식별하는 서비스가 아닙니다. 사진의 글자 인식, Google 사이트 검색 링크, *사용자가 검증한 시세 기록*을 조합합니다. 검색 결과나 수익 예측은 구매·판매 보증이 아닙니다.

## 실행

### 가장 간단한 방법

ZIP 압축 해제 → `index.html`을 브라우저에서 엽니다. 기본 상품 입력 / 무료 검색 링크 / 수익 계산 / 로컬 시세 기록은 브라우저에서 작동합니다. 일부 브라우저에서는 `file://` 환경에서 OCR 워커가 제한되므로 아래의 정적 웹서버나 GitHub Pages를 권장합니다.

### 로컬 서버 (권장)

```bash
cd Price_Hunter_v0.1.0
python -m http.server 8000
```

`http://localhost:8000` 접속. PWA 서비스 워커는 `https:` 또는 `localhost` 보안 컨텍스트에서만 등록됩니다. **휴대폰에서 PC의 LAN IP로 접속하는 경우 카메라/PWA 기능이 HTTPS 요구로 제한될 수 있습니다.**

### GitHub Pages (무료)

1. 새 GitHub 저장소의 루트에 `index.html`, `core.js`, `app.js`, `sw.js`, `manifest.webmanifest`, `assets/`를 함께 업로드합니다.
2. Repository Settings → Pages → Build and deployment → `Deploy from a branch` → `main` / `(root)`를 선택합니다.
3. HTTPS로 제공되는 Pages 사이트를 휴대폰 Chrome/Edge에서 엽니다.
4. PWA가 허용되면 브라우저 메뉴에서 `홈 화면에 추가` / `앱 설치`를 사용할 수 있습니다.

## 실사용 흐름

1. 제품 사진과 매장 가격표 촬영 후 `한글·영문 OCR 분석` 또는 직접 상품명을 입력합니다. 한국어/영어 OCR은 무료 오픈소스 Tesseract.js 6.0.1을 CDN에서 불러옵니다. 첫 실행에는 네트워크 다운로드가 필요하고, 이후에도 오프라인 OCR 동작은 보장하지 않습니다.
2. `정확한 상품명` 및 `매장 구매가`를 수동 확인해 확정합니다. 선택한 브라우저에서 BarcodeDetector를 지원하면 제품 바코드 추출을 시도합니다. 지원하지 않으면 직접 입력합니다.
3. 무료 Google 사이트 검색 (`site:web.joongna.com`, `site:daangn.com`, `site:bunjang.co.kr` 등)을 눌러 원본 매물을 확인합니다. Google Lens 링크도 제공합니다.
4. 검증한 매물의 가격, 상태, 날짜, 원본 링크와 상품 일치 여부를 기록합니다. 링크/가격/모델 불일치 및 중복은 제한합니다.
5. 최근 1/3/6/12개월 또는 전체 기간을 필터링합니다. **판매중 호가**, **판매완료 표시(실거래가 미확인)**, **실거래 확인**, **신품가**를 구분해 통계에 반영합니다.
6. 배송비, 포장비, 플랫폼 수수료, 할인 협상액, 기타 비용, 세금 입력값을 차감하여 순이익을 계산합니다. 분석 결과는 브라우저 로컬에 저장하고 JSON으로 백업/복원할 수 있습니다.

## 정확도/검증 원칙

- OCR은 **문자 인식**이지 정확한 상품 모델 보증이 아닙니다. 표면에 브랜드/제품 텍스트가 없는 사진은 Google Lens 등 외부 이미지 검색으로 보완합니다.
- 제품 일치 검사에서 모델 코드 불일치를 감지하면 시세 등록을 차단하고, 일치가 불명확하면 수동 확인을 요구합니다.
- 검색 결과의 호가, 판매완료 표시, 실제 송금액은 서로 다릅니다. 실거래라고 분류하려면 실제 거래 금액을 확인해야 합니다.
- 가격 통계는 **사용자가 기록한 표본만** 반영합니다. 가상의 자료를 생성하거나 온라인 최저가를 꾸며내지 않습니다. 표본이 적으면 통계가 불확실하다고 경고합니다.
- 사용자 로컬 기기에 기록이 남습니다. 저장 공간 삭제에 대비하여 JSON 백업을 권장합니다.
- 6개월 전 시세는 오래된 매물을 지금 수집한다고 복원되지 않습니다. 실제로 축적된 날짜가 있는 데이터만 시간 필터로 조회합니다.
- 웹사이트의 로그인 우회, 검색 제한 우회, 무단 크롤링, 외부 API 키 하드코딩을 수행하지 않습니다.

## 구조

- `index.html`: 모바일 반응형 UI / 화면 다섯 개
- `app.js`: OCR/바코드/검색 링크/수익 분석/로컬 저장 연동
- `core.js`: 독립 테스트 가능한 상품 일치·가격 추출·시세 및 계산 엔진
- `sw.js`, `manifest.webmanifest`, `assets/icon.svg`: PWA 기반
- `tests/core.test.js`: 단위 테스트 (`node tests/core.test.js`)
- `HANDOFF_CUMULATIVE.md`: 상태, 테스트 및 향후 패치 가이드

## 보안 및 비용

유료 API 없음, 서버 계정 필요 없음, 외부 AI API 키 사용 없음. OCR 라이브러리/언어팩 최초 다운로드 시 무료 CDN 및 학습데이터 호스트에 접속합니다. 본 앱의 제품 이미지는 해당 브라우저 내부 OCR 처리에 사용되고 자체 서버로 전송하지 않습니다. 다만 외부 검색 사이트나 Lens를 열어 사진을 업로드한다면 해당 서비스의 개인정보 처리방침이 적용됩니다.

## 현재 구현하지 않은 것

- 전 중고 플랫폼 매물의 완전자동 실시간 수집/공식 API 접근
- 신규 등록 이전의 과거 1~12개월 실거래가 자동 확보
- 아무 글자 없는 상품 사진의 정확한 모델명 자동 판단
- APK 바이너리 생성, OS 알림/백그라운드 실시간 감시
- 외부 플랫폼 내부 데이터를 자동 사용해 산출하는 검증된 중고 시장 평균

향후 단계는 각 플랫폼의 정식 접근권한을 확보한 가격 데이터 연동, Florence-2 등 오픈소스 이미지 모델의 오프라인 성능 측정, 사진 OCR 교정 UI, Android WebView/Capacitor APK 패키징입니다.
