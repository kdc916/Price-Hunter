# 국내 쇼핑몰 가격 표기 연구 — Price Hunter v0.5.0

## 목적
사진 한 장의 OCR 텍스트에서 **제품의 일반 판매가**와 그 밖의 금액을 보수적으로 분리. 유료 AI API 및 무단 쇼핑몰 크롤링 없이 브라우저에서 동작하는 후처리 엔진을 개발.

## 조사·지원 대상
- 네이버쇼핑 (shopping.naver.com): 판매가·최저가, 네이버페이 포인트/적립금.
- 다나와 (danawa.com): 최저가, 쇼핑몰별 가격, 배송비 포함 옵션, 멤버십/카드결제 최대 혜택가. 여러 판매점의 서로 다른 가격을 같은 판매가로 취급하지 않음.
- 신세계TV쇼핑 (shinsegaetvshopping.com): 판매가, 방송혜택/할인, 적립·회원 혜택.
- SSG.COM / 이마트몰 (ssg.com / emart.ssg.com): 판매가, 쿠폰·회원 혜택, 배송비.
- 11번가 (11st.co.kr): 판매가, 쿠폰/회원가, 적립.
- G마켓 (gmarket.co.kr): 판매가와 쿠폰적용가. 실제 G마켓 개발·판매자 공지에서도 쿠폰적용가를 별도의 가격 정보로 설명함.
- 옥션 (auction.co.kr): 판매가, 스마일캐시·쿠폰·카드 할인.
- 쿠팡 (coupang.com): 할인가, 이전가격(취소선), 개당·중량당 단가, 쿠팡캐시 적립. 쿠폰할인/와우 조건은 기본가격과 구분.
- 롯데ON (lotteon.com), CJ온스타일, 현대Hmall, GS SHOP, 롯데하이마트, 홈플러스, AK몰, 카카오쇼핑.

쇼핑몰 로고/사이트명이 OCR 문장에 나타난 경우에만 브랜드 ID를 부여함. 쇼핑몰명 자체가 식별되지 않으면 일반 규칙 적용 및 '미확인' 표시.

## 금액 역할
- 일반가(main): 판매가·최저가·행사가·할인가·현재가. 문맥이 약해도 충돌 없는 단일 원화금액이면 자동 입력 허용.
- 할인 전(original): 정가·소비자가·정상가·권장가격·할인 전 금액.
- 조건부(conditional): 쿠폰 적용, 카드 결제, 회원·멤버십, 무통장입금, 로그인, 와우 할인가 등.
- 제외(excluded): 적립금·포인트·캐시백·배송비·수수료·할부금·단위당 가격·렌탈료·할인액.
- 합계(total): 총 상품금액·주문합계·결제예정액. 판매가와 같은 값의 복제 표시로 취급, 새 관측치나 독립된 가격 근거로 취급하지 않음.

## 인식과 선택
1. OCR 문장별 원화 단위가 확인되는 숫자만 후보로 추출. SKU·할인율·용량은 금액으로 보지 않음.
2. 가격의 앞·뒤 및 가격 라벨만 따로 있는 직전 줄의 문구로 역할 분류.
3. 전체 OCR/고대비 OCR/상품명 영역/가격 영역의 각각 다른 결과를 값 기준으로 교차 검증.
4. 같은 금액을 한 OCR에서는 회원 혜택가로, 다른 OCR에서는 일반가로 읽으면 기본 구매가 자동 입력을 보류.
5. 여러 일반가가 나오면 명확한 대표 최저가를 선택할 수 있는 경우 외에는 자동 적용을 보류.
6. 신품 최저가 및 중고 가격은 외부 매물의 동일 SKU, 제품 상태·구성·배송비·시점까지 확인해야 직접 비교 가능. '실거래가'와 '매물 호가'를 혼동하지 않음.
