STEP 03 / AUTOMATIC MULTI-MARKET SEARCH

🔎 중고시장 통합 검색

인식한 미선택 모델을 기준으로 중고나라·번개장터·당근·네이버 중고나라를 한 번에 검색합니다. 마켓 선택이 필요 없습니다.

구글 전체 결과 ↗
검색 준비 중입니다. 관리자 CX 연결 시 앱 안에서 검색하고, 미연결 시 Google에서 한 번에 중고 마켓을 검색합니다.
상품을 확정하면 여기에서 여러 중고 마켓의 결과를 함께 보여줍니다.

Google에 공개 색인된 게시물만 노출됩니다. 검색 결과의 가격은 판매 희망가격 후보이며 실제 거래 완료가가 아닙니다. 가격과 모델이 확실하지 않으면 통계·예상 순익에 자동 포함하지 않습니다.

매물 정보 수동 검증·기록 (선택)

자동 검색에 나오지 않는 매물은 복사한 제목과 가격을 직접 확인해 추가할 수 있습니다.

⚙ 무료 자동 검색 연결 (사이트 관리자 최초 1회)

Google Programmable Search Engine의 무료 Standard Search Element를 만드세요. 이 작업에는 사이트 소유자의 Google 로그인 인증이 필요합니다. 대상 사이트에 joongna.com, bunjang.co.kr, daangn.com, cafe.naver.com 등을 지정하고 검색 엔진 ID(CX)를 입력하세요. 광고가 포함될 수 있습니다. 일반 사용자에게는 별도의 회원가입이 필요하지 않습니다.

무료 검색 엔진 만들기 ↗

ID를 연결하면 현재 브라우저에서 앱 안 통합 검색이 작동합니다. ID가 없을 때도 버튼 한 번으로 Google 다중 마켓 검색이 열립니다. 모든 사용자가 기본 연결을 이용하도록 하려면 관리자가 market-config.js의 공개 CX 값을 저장소에 반영해야 합니다. 비밀번호나 API 키를 입력하지 마세요.
